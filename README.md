# LingoCode

Бесплатное приложение для самостоятельного изучения английского (A0 → C2), Python и HTML. Полностью на русском, без рекламы, регистрации и интернета.

## Что уже работает (этап 1)

- **Первый запуск**: имя, направления, нагрузка, учебные дни, старт с A0 или диагностический тест, готовый план.
- **Английский A0** — 15 уроков: алфавит, звуки, правила чтения, приветствия, числа, цвета, животные, еда, семья, дни и месяцы, местоимения, to be, вопросы. 106 слов с транскрипцией и озвучкой. Итоговый тест уровня (порог 80%).
- **Python, основы** — 13 уроков (print, переменные, типы, арифметика, input, if, for, while, списки, словари, функции) и 3 проекта: калькулятор, «Угадай число», список покупок.
- **HTML, основы** — 12 уроков (структура, заголовки, текст, ссылки, картинки, списки, таблицы, формы, атрибуты, семантика, доступность) и 3 проекта: первая страница, «Обо мне», визитка.
- **10 типов упражнений**: выбор, аудирование, ввод, составление предложения, пары, поиск ошибки, свободное письмо, чтение с вопросами, задачи на Python, задания по HTML. Ошибки повторяются в конце урока, затем идёт мини-тест.
- **Редактор Python**: подсветка, автоотступы, панель символов, запуск, ввод для `input()`, ошибки с объяснением на русском, подсказки по шагам, решение — только после 3 неудачных попыток. Код выполняется настоящим CPython (Pyodide) в изолированном потоке: без сети, с виртуальной файловой системой, ограничением времени и объёма вывода.
- **Редактор HTML**: предпросмотр в реальном времени в изолированном iframe, проверка структуры документа (а не текста), предупреждения о незакрытых тегах.
- **Песочницы** для своих программ и страниц.
- **Словарь и карточки** с интервальным повторением (Не помню / Трудно / Хорошо / Легко), избранное, сложные слова.
- **Календарь**: месяц/год, зелёный/жёлтый/серый/синий, детали дня (уроки, время, XP, слова, темы), свои задания с ручной отметкой, перенос невыполненного, дни отдыха. Учебные задания нельзя отметить вручную — только выполнить.
- **XP и уровни** по таблице из ТЗ; каждая награда выдаётся один раз. Серия дней (отдых её не прерывает), 14 достижений с анимацией.
- **Прогресс**: графики за неделю/месяц/год, регулярность, статистика по курсам.
- **Данные**: автосохранение, восстановление незаконченного урока, резервная копия в файл и восстановление.
- Светлая, тёмная и системная темы.

## Структура

```
web/                 приложение (HTML/CSS/JS без сборки) — оно же будущая веб-версия
  js/content/        учебные материалы (как добавлять — см. README внутри)
  js/screens/        экраны
  js/python/         песочница Python
  vendor/pyodide/    Python 3.12 для WebAssembly (офлайн)
android/             Android-оболочка на Kotlin (WebView, озвучка, файлы)
.github/workflows/   сборка APK в GitHub Actions
```

## Сборка APK

Загрузите проект в репозиторий GitHub — workflow «Сборка APK» запустится сам. Готовый `LingoCode.apk` будет во вкладке **Actions → последняя сборка → Artifacts**.

Локально: `cd android && ./gradlew assembleRelease` (нужны JDK 17 и Android SDK).

## Веб-версия

Папка `web/` — это готовый сайт. Для проверки: `cd web && python3 -m http.server 8000` и откройте `http://localhost:8000`. Озвучка в браузере идёт через Web Speech API.
