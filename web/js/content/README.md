# Как добавлять уроки

Уроки — это обычные JS-файлы с данными. Код приложения менять не нужно.

1. Создайте файл, например `en-a1.js`, по образцу `en-a0.js` (`export default [ ...уроки ]`).
2. В `index.js` импортируйте его и укажите в нужном юните: `{ id: 'en-A1', ..., lessons: enA1, pass: 80 }`.
   Юнит без `lessons` показывается в программе как «Готовится».
3. `id` урока должен быть уникальным и **никогда не меняться** — по нему хранится прогресс и XP.

## Урок

```js
{
  id: 'en-a1-01', title: 'Название', goal: 'Цель урока',
  theory: [ ...блоки ],
  words: [{ en, ru, tr, ex, exRu }],   // попадут в словарь и интервальное повторение
  exercises: [ ...упражнения ],
  quiz: [ ...вопросы мини-теста ],       // типы choice / listen / input
}
```

Проекты (`project: true, after: 'id урока'`) открываются после указанного урока и дают +100 XP.

## Блоки теории

| t | Поля |
|---|---|
| `p` | `text` — поддерживает `**жирный**`, `` `код` `` и переносы `\n` |
| `tip` | `text` — жёлтая подсказка |
| `ex` | `en, ru, tr?` — пример с кнопкой озвучки |
| `table` | `head, rows, say?` — `say: 0` делает колонку 0 озвучиваемой |
| `letters` | `items: [{ l, say, name, tr, w }]` — карточки букв |
| `code` | `code, lang?` (`'html'`) |

## Упражнения

| k | Поля | Проверка |
|---|---|---|
| `choice` | `q, opts, a, code?, say?, why` | индекс верного ответа `a` |
| `listen` | `say, q, opts, a` | озвучка + выбор |
| `input` | `q, a: [варианты], caseSensitive?, hint?` | без учёта регистра, пробелов и конечной пунктуации |
| `order` | `q, words, a: [варианты]` | составить предложение |
| `match` | `pairs: [[en, ru]]` | засчитывается при ≤ 1 ошибке |
| `error` | `q, tokens, a, fix?` | найти ошибочный фрагмент |
| `write` | `q, need: [regex], sample` | свободный ответ по шаблону |
| `read` | `text, textRu?, qs: [{ q, opts, a }]` | текст с вопросами |
| `py` | `task, starter, tests: [{ in, out }], check?, need?, pre?, hints, solution` | настоящий запуск Python |
| `html` | `task, starter, checks, src?, hints, solution` | анализ структуры DOM |

### Проверки HTML (`checks`)

- `{ sel: 'css-селектор', min, max, text: 'regex', attr, attrRe, msg }`
- `{ style: 'regex по содержимому <style>', msg }`
- `{ labels: true, msg }` — у каждого поля формы есть `<label>`
- `{ anchors: true, msg }` — ссылки меню ведут на существующие `id`
- `src: [{ re, msg }]` — проверка исходника (для doctype и того, что браузер «чинит» сам)
